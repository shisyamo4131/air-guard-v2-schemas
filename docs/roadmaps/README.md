# Roadmaps

This directory is the source of truth for planned work, milestone order, unresolved blockers, and evidence-backed progress. ../specification.md remains authoritative for confirmed requirements.

## Progress Method

- Milestone weights total 100.
- Credit is earned only for completed gates with repository, validation, review, release, or consumer evidence.
- Partial credit is allowed only for sub-gates defined before credit is claimed.
- Every partial result states the completed sub-gate and remaining acceptance.
- Scope changes update the specification, roadmap, ADRs, operations, changelog, implementation, and tests together as applicable.
- A decrease records the previous value, new value, reason, and evidence.
- One reviewable checkpoint is active at a time. Continue only after callback and coordinator review while safe independent work remains.
- A work session ends when safe independent work is exhausted or the user instructs a stop.
